Entry for the make.fun bounty "Sum up 17 November's world news in one image". `entry.png` is a 1024×1024 newspaper front page, "THE WORLD TODAY — TUESDAY 17 NOVEMBER 2026", with six stories that defined the day, each with its own scene picture, kicker, headline and one-line summary: Kerch Bridge span collapses after a second Ukrainian strike in two days; tankers hit mines near Hormuz as a third US carrier arrives; Trump in Manila with a Xi summit set; Pentagon fails its audit for the 9th year ($4.8 trillion unverified); ULA's Vulcan underperforms and 40 satellites are lost; five states plan a Rwanda return hub. Footer ticker: JPMorgan blames a software bug for Monday's outage; Nvidia reports its first earnings since Huang's exit; Houthis push Yemen forces back from the Red Sea coast. All stories were reported on 17 November 2026 (BBC, CNN, AP, Reuters, Bloomberg, ULA). Scene pictures are AI-generated illustrations (no text in them); all headlines, the date and labels are real text drawn onto the page, so the image reads cleanly at small sizes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`). No network access; both runs write identical bytes.
